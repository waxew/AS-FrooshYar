# فروشیار نسخه 1

## ماژول‌های اصلی

### فروش
- ثبت فروش سریع
- انتخاب کالا
- تعداد و قیمت
- تخفیف
- محاسبه مبلغ نهایی
- ثبت پرداخت

### فاکتور
- شماره فاکتور خودکار
- تاریخ و ساعت ثبت
- لیست اقلام
- مبلغ کل
- وضعیت پرداخت
- چاپ و خروجی

### مشتریان
- نام
- شماره تماس
- آدرس
- سوابق خرید
- بدهی و تسویه

### کالاها
- نام کالا
- دسته‌بندی
- قیمت خرید
- قیمت فروش
- موجودی
- تصویر کالا

### انبار
- ورود کالا
- خروج کالا
- هشدار کمبود موجودی

### گزارش‌ها
- فروش روزانه
- فروش ماهانه
- سود تقریبی
- کالاهای پرفروش

## الزامات
