# معماری دیتابیس فروشیار

## نوع ذخیره سازی

نسخه اول کاملا Offline First است.

Database:

`frooshyar.db`

## جداول اصلی

### customers

اطلاعات مشتریان:
- نام
- شماره تماس
- آدرس
- توضیحات

### products

کالاها:
- نام کالا
- دسته بندی
- قیمت
- موجودی

### invoices

فاکتورها:
- شماره فاکتور
- مشتری
- مبلغ کل
- مبلغ پرداخت شده
- تاریخ

### invoice_items

اقلام هر فاکتور:
- کالا
- تعداد
- قیمت

### settings

تنظیمات کاربر و برنامه.

## قوانین آپدیت

- افزایش نسخه دیتابیس با Migration انجام می‌شود.
- اطلاعات کاربر حذف نمی‌شود.
- Backup قبل از Migration گرفته می‌شود.
